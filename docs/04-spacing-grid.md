# 04 · SPACING & GRID

Valores em `tokens/spacing.css`.

## Base-8
Unidade = 8px. Escala `--space-1..10` (2,4,8,12,16,24,32,48,64,96). Sub-unidades 2/4px só para detalhes de ícone. **Toda métrica de layout é múltiplo de 8.**

## Radii (Bouba suave-mas-estrutural)
`--radius-xs 2` · `sm 4` · `md 8` · `lg 12` · `xl 16` · `pill 999`. Cantos têm raio — nunca cantos vivos agressivos, nunca pílula sem função.

## Grid de layout
Colunas em múltiplos de 8; gutters 16/24px; margens de tela 16/24/32px conforme breakpoint. Ritmo vertical em 8px (baseline).
