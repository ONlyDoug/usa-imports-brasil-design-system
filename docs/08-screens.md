# 08 · SCREENS / FLUXOS

Onde o sistema "vira produto". Cada tela monta componentes (docs/06 + 07) sobre foundations. Todas em Dark Mode, fundo `--bg-base`, header com symboltipo horizontal.

## Telas-âncora a gerar
1. **Rastreio do pedido** — herói com selo "Visão de Águia" + timeline de rastreamento + código mono. A tela que mais expressa a tese.
2. **Produto / curadoria** — ficha de produto importado com selo de autenticidade, specs em mono, CTA primary. Comunica "o olhar que seleciona".
3. **Selo de garantia / autenticação** — tela/modal dedicada ao selo, estados autenticado/negado.
4. **Status / dashboard operacional** — blocos de telemetria, KPIs (big-number 900), lista de pedidos com badges de estado.
5. **Home / landing** — manifesto "Visão de Águia", symboltipo em destaque, hierarquia display 900.

## Regras de tela
- Margem de tela e grid em múltiplos de 8.
- Uma voz por superfície: títulos Next Sphere all-caps (Águia); corpo/UI Inter (U.B.I.).
- Acento azul/vermelho só em estado e CTA — o resto é Navy + off-white.
- Mobile-first; alvos ≥40px; foco visível.

## Responsividade
Breakpoints sugeridos (múltiplos de 8): 360 / 768 / 1024 / 1440. Symboltipo colapsa para empilhado/símbolo isolado em telas estreitas.
