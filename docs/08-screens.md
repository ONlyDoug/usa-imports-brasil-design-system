# 08 · APP SCREENS (kit de referência de UI)

Telas **funcionais de aplicação** que demonstram componentes do sistema em uso real. NÃO são peças de marketing.

> **FORA DE ESCOPO (não gerar):** landing page, home institucional/marketing, hero de campanha. Landing é asset de marketing construído depois, **não pertence ao design system técnico**. Não crie `templates/landing` nem `HomeScreen` de marketing.

## Telas a gerar (todas Dark Mode, header com symboltipo horizontal)
1. **Rastreio do pedido** — selo "Visão de Águia" + timeline de rastreamento + código em mono. A tela que mais expressa a tese.
2. **Produto / curadoria** — ficha de produto importado, selo de autenticidade, specs em mono, CTA primary.
3. **Status / dashboard operacional** — blocos de telemetria, KPIs (big-number 900), lista de pedidos com badges de estado.

## Regras de tela
- Margem e grid múltiplos de 8. Uma voz por superfície (títulos Next Sphere all-caps; corpo/UI Inter).
- Azul/vermelho só em estado e CTA. O resto é Navy + off-white. Mobile-first; alvos ≥40px; foco visível.
- Telas existem para **provar os componentes**, não para vender. Sóbrias, instrumentais.
